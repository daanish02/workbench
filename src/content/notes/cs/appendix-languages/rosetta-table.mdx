This table lines up the same concept across the seven languages that have their own sheet: [Python](../python-sheet/), [TypeScript](../javascript-typescript/), [Go](../go-sheet/), [C](../c-sheet/), [C++](../cpp-sheet/), [Java](../java-sheet/) and [Rust](../rust-sheet/). Each cell is the idiomatic spelling, not the only one; "none" means the language has no direct equivalent. Use it to translate an idea you know into a language you are learning, then read that language's sheet for the semantics. The higher-level comparison (typing, runtime, typical uses) is in [Language Reference](../language-reference/). Type in the box to filter, for example "map", "thread" or "null".

### Basics

| Concept | Python | TypeScript | Go | C | C++ | Java | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Print a line | `print(x)` | `console.log(x)` | `fmt.Println(x)` | `printf("%d\n", x);` | `std::cout << x << "\n";` | `System.out.println(x);` | `println!("{x}");` |
| Variable | `x = 1` | `let x = 1;` | `x := 1` | `int x = 1;` | `auto x = 1;` | `var x = 1;` | `let mut x = 1;` |
| Constant | `MAX = 10` (convention) | `const MAX = 10;` | `const Max = 10` | `const int MAX = 10;` | `constexpr int kMax = 10;` | `static final int MAX = 10;` | `const MAX: i32 = 10;` |
| Comment | `# text` | `// text` | `// text` | `/* text */` or `// text` | `// text` | `// text` | `// text` |
| Integer division | `7 // 2` | `Math.trunc(7 / 2)` | `7 / 2` | `7 / 2` | `7 / 2` | `7 / 2` | `7 / 2` |
| Conditional expression | `a if c else b` | `c ? a : b` | none (use `if`) | `c ? a : b` | `c ? a : b` | `c ? a : b` | `if c { a } else { b }` |
| Counting loop | `for i in range(n):` | `for (let i = 0; i < n; i++)` | `for i := range n` | `for (int i = 0; i < n; i++)` | `for (int i = 0; i < n; i++)` | `for (int i = 0; i < n; i++)` | `for i in 0..n` |
| Loop over items | `for x in xs:` | `for (const x of xs)` | `for _, x := range xs` | index loop | `for (const auto& x : xs)` | `for (var x : xs)` | `for x in &xs` |
| While loop | `while c:` | `while (c)` | `for c { }` | `while (c)` | `while (c)` | `while (c)` | `while c { }` |
| Multi-way branch | `match x:` | `switch (x)` | `switch x { }` | `switch (x)` | `switch (x)` | `switch (x) { case 1 -> … }` | `match x { 1 => … }` |

### Functions

| Concept | Python | TypeScript | Go | C | C++ | Java | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Define a function | `def f(a: int) -> int:` | `function f(a: number): number` | `func f(a int) int` | `int f(int a)` | `int f(int a)` | `static int f(int a)` | `fn f(a: i32) -> i32` |
| Anonymous function | `lambda x: x * 2` | `(x) => x * 2` | `func(x int) int { return x * 2 }` | none (function pointer) | `[](int x) { return x * 2; }` | `x -> x * 2` | `\|x\| x * 2` |
| Return two values | `return a, b` | `return [a, b];` | `return a, b` | struct or out-pointer | `return std::pair{a, b};` | return a `record` | `(a, b)` |
| Default argument | `def f(a=1):` | `function f(a = 1)` | none | none | `int f(int a = 1)` | overloads | none |
| Variadic | `def f(*args):` | `function f(...args: number[])` | `func f(args ...int)` | `int f(int n, ...)` | variadic template | `int f(int... args)` | macro (`println!`) |
| Closure over a variable | `def g(): return n` | `() => n` | `func() int { return n }` | none | `[n]() { return n; }` | `() -> n` | `move \|\| n` |

### Collections

| Concept | Python | TypeScript | Go | C | C++ | Java | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Growable array | `xs = [1, 2]` | `const xs = [1, 2];` | `xs := []int{1, 2}` | `malloc` + `realloc` | `std::vector<int> xs{1, 2};` | `new ArrayList<>(List.of(1, 2))` | `let mut xs = vec![1, 2];` |
| Append | `xs.append(3)` | `xs.push(3)` | `xs = append(xs, 3)` | write and grow by hand | `xs.push_back(3);` | `xs.add(3);` | `xs.push(3);` |
| Length | `len(xs)` | `xs.length` | `len(xs)` | track it yourself | `xs.size()` | `xs.size()` | `xs.len()` |
| Hash map | `d = {"a": 1}` | `new Map([["a", 1]])` | `map[string]int{"a": 1}` | none (library) | `std::unordered_map<std::string, int>` | `new HashMap<String, Integer>()` | `HashMap::from([("a", 1)])` |
| Lookup with default | `d.get(k, 0)` | `m.get(k) ?? 0` | `v, ok := m[k]` | none | `m.contains(k) ? m.at(k) : 0` | `m.getOrDefault(k, 0)` | `m.get(k).copied().unwrap_or(0)` |
| Set | `{1, 2}` | `new Set([1, 2])` | `map[int]struct{}` | none (library) | `std::unordered_set<int>` | `new HashSet<Integer>()` | `HashSet::from([1, 2])` |
| Sort in place | `xs.sort()` | `xs.sort((a, b) => a - b)` | `slices.Sort(xs)` | `qsort(xs, n, sizeof *xs, cmp)` | `std::ranges::sort(xs);` | `Collections.sort(xs);` | `xs.sort();` |
| Filter and map | `[x * x for x in xs if x > 0]` | `xs.filter(x => x > 0).map(x => x * x)` | a `for` loop | a `for` loop | `xs \| std::views::filter(pos) \| std::views::transform(sq)` | `xs.stream().filter(x -> x > 0).map(x -> x * x).toList()` | `xs.iter().filter(\|x\| **x > 0).map(\|x\| x * x).collect()` |
| Slice of a sequence | `xs[1:3]` | `xs.slice(1, 3)` | `xs[1:3]` | pointer + length | `std::span(xs).subspan(1, 2)` | `xs.subList(1, 3)` | `&xs[1..3]` |

### Strings

| Concept | Python | TypeScript | Go | C | C++ | Java | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Interpolate | `f"{name}!"` | `` `${name}!` `` | `fmt.Sprintf("%s!", name)` | `snprintf(buf, n, "%s!", name)` | `std::format("{}!", name)` | `String.format("%s!", name)` | `format!("{name}!")` |
| Split | `s.split(",")` | `s.split(",")` | `strings.Split(s, ",")` | `strtok(s, ",")` | `std::views::split(s, ',')` | `s.split(",")` | `s.split(',')` |
| Join | `",".join(xs)` | `xs.join(",")` | `strings.Join(xs, ",")` | loop with `strcat` | loop or `std::views::join_with` | `String.join(",", xs)` | `xs.join(",")` |
| Length counts | code points | UTF-16 units | bytes | bytes (to the `'\0'`) | bytes | UTF-16 units | bytes (`chars().count()` for chars) |
| Parse an integer | `int("42")` | `Number.parseInt("42", 10)` | `strconv.Atoi("42")` | `strtol("42", &end, 10)` | `std::stoi("42")` | `Integer.parseInt("42")` | `"42".parse::<i32>()` |
| Compare contents | `a == b` | `a === b` | `a == b` | `strcmp(a, b) == 0` | `a == b` | `a.equals(b)` | `a == b` |

### Types

| Concept | Python | TypeScript | Go | C | C++ | Java | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Record type | `@dataclass class P: x: int` | `type P = { x: number }` | `type P struct { X int }` | `struct P { int x; };` | `struct P { int x; };` | `record P(int x) {}` | `struct P { x: i32 }` |
| Method | `def norm(self):` | `norm(): number { … }` | `func (p P) Norm() float64` | `double p_norm(const P *p)` | `double norm() const;` | `double norm() { … }` | `impl P { fn norm(&self) -> f64 }` |
| Interface | `class Shape(Protocol):` | `interface Shape { area(): number }` | `type Shape interface { Area() float64 }` | struct of function pointers | abstract class or `concept` | `interface Shape { double area(); }` | `trait Shape { fn area(&self) -> f64; }` |
| Generic function | `def f[T](x: T) -> T:` | `function f<T>(x: T): T` | `func f[T any](x T) T` | `void *` or `_Generic` | `template <typename T> T f(T x)` | `static <T> T f(T x)` | `fn f<T>(x: T) -> T` |
| Absence of a value | `None` | `null`, `undefined` | `nil` | `NULL` | `nullptr`, `std::optional<T>` | `null`, `Optional<T>` | `Option<T>` (`None`) |
| Sum type | `enum.Enum`, union of classes | union of object types | constants with `iota` | `enum` + `union` | `std::variant<A, B>` | sealed interface + records | `enum` with data |
| Type check at run time | `isinstance(x, int)` | `typeof x === "number"` | `v, ok := x.(int)` | none | `dynamic_cast<D*>(p)` | `x instanceof Integer i` | `match` on an `enum` |

### Errors

| Concept | Python | TypeScript | Go | C | C++ | Java | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Signal an error | `raise ValueError("bad")` | `throw new Error("bad")` | `return errors.New("bad")` | `return -1;` and set `errno` | `throw std::runtime_error("bad");` | `throw new IllegalArgumentException("bad");` | `return Err("bad".into());` |
| Handle an error | `try: … except ValueError as e:` | `try { … } catch (e) { … }` | `if err != nil { … }` | check the return value | `try { … } catch (const std::exception& e) { … }` | `try { … } catch (Exception e) { … }` | `match r { Ok(v) => …, Err(e) => … }` |
| Pass it upward | let it propagate | let it propagate | `return fmt.Errorf("ctx: %w", err)` | return the code again | let it propagate | `throws` or propagate | `?` |
| Guaranteed cleanup | `with open(p) as f:` | `try { … } finally { … }` | `defer f.Close()` | `goto cleanup;` | destructor (RAII) | try-with-resources | `Drop` at end of scope |
| Unrecoverable failure | `sys.exit(1)` | `process.exit(1)` | `panic("bad")` | `abort()` | `std::terminate()` | `System.exit(1)` | `panic!("bad")` |

### Memory

| Concept | Python | TypeScript | Go | C | C++ | Java | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Who frees memory | reference counting + cycle collector | tracing GC | tracing GC | you: `free` | destructors, smart pointers | tracing GC | ownership: freed when the owner goes out of scope |
| Allocate on the heap | implicit | implicit | implicit (escape analysis) | `malloc(sizeof(T))` | `std::make_unique<T>()` | `new T()` | `Box::new(x)` |
| `b = a` with an object | both names refer to one object | both refer to one object | copies the value (slices and maps share data) | copies the value | copies the value | both refer to one object | moves it (or copies `Copy` types) |
| Explicit copy | `copy.deepcopy(a)` | `structuredClone(a)` | `slices.Clone(a)` | `memcpy` | copy constructor | `clone()` or a copy constructor | `a.clone()` |
| Shared ownership | default | default | default | by hand | `std::shared_ptr<T>` | default | `Rc<T>`, `Arc<T>` |

### Concurrency

| Concept | Python | TypeScript | Go | C | C++ | Java | Rust |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Start a thread | `threading.Thread(target=f).start()` | `new Worker("w.js")` | `go f()` | `pthread_create(&t, NULL, f, NULL)` | `std::jthread t(f);` | `Thread.ofVirtual().start(r)` | `std::thread::spawn(f)` |
| Wait for it | `t.join()` | `worker.onmessage` | `sync.WaitGroup` | `pthread_join(t, NULL)` | `t.join()` (automatic for `jthread`) | `t.join()` | `handle.join()` |
| Mutual exclusion | `threading.Lock()` | not needed (one thread) | `sync.Mutex` | `pthread_mutex_t` | `std::mutex` | `synchronized`, `ReentrantLock` | `Mutex<T>` |
| Atomic counter | none (use a lock) | `Atomics.add` on shared memory | `atomic.Int64` | `atomic_long` | `std::atomic<long>` | `AtomicLong` | `AtomicU64` |
| Message passing | `queue.Queue` | `postMessage` | channels | none (library) | none (library) | `BlockingQueue` | `mpsc::channel()` |
| Async I/O | `async def` / `await` | `async` / `await` | goroutines (blocking calls are cheap) | none (event library) | coroutines (`co_await`) | virtual threads, `CompletableFuture` | `async fn` / `.await` with Tokio |

<Callout type="pitfall">
Similar syntax can hide different semantics. `b = a` copies in C, C++ and Go but aliases in Python, TypeScript and Java and moves in Rust; `==` on strings compares contents in Python, Go, C++ and Rust but references in Java; a string's length is code points in Python, UTF-16 units in TypeScript and Java and bytes elsewhere. When translating code, check these rows first, because the translated program will compile and run, just with a different meaning.
</Callout>
