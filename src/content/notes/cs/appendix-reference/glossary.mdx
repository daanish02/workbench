### General

| Term | Meaning | Learn more |
| --- | --- | --- |
| **Abstraction** | Hiding detail behind a simpler interface so you can use something without knowing how it works | [Abstraction Layers](../../foundations/abstraction-layers/) |
| **Algorithm** | A finite, precise sequence of steps that solves a problem | [Algorithmic Thinking](../../foundations/algorithmic-thinking/) |
| **Big O** | Notation describing how an algorithm's cost grows with input size, ignoring constants | [Big-O Notation](../../algorithms/big-o-notation/) |
| **Concurrency** | Managing several tasks that overlap in time, whether or not they run at the same instant | [Concurrency Models](../../languages/concurrency-models/) |
| **Parallelism** | Actually running several computations at the same instant on multiple cores | [Processes and Threads](../../operating-systems/processes-and-threads/) |
| **Process** | A running program with its own memory space | [Processes and Threads](../../operating-systems/processes-and-threads/) |
| **Thread** | A path of execution inside a process; threads of one process share its memory | [Processes and Threads](../../operating-systems/processes-and-threads/) |
| **Race condition** | A bug where the result depends on the unpredictable timing of concurrent operations | [Synchronization](../../operating-systems/synchronization/) |
| **Deadlock** | Tasks waiting on each other forever, so none can proceed | [Deadlocks](../../operating-systems/deadlocks/) |
| **Recursion** | A function defined in terms of itself, with a base case that stops it | [Recursion](../../algorithms/recursion/) |
| **Compiler / interpreter** | A compiler translates a whole program to machine code ahead of time; an interpreter executes it step by step | [Compilers and Interpreters](../../languages/compilers-and-interpreters/) |
| **Static vs dynamic typing** | Types checked before the program runs vs while it runs | [Type Systems](../../languages/type-systems/) |
| **Kernel** | The core of an operating system, managing hardware, memory and processes | [Kernel Architecture](../../operating-systems/kernel-architecture/) |
| **System call** | The way a program asks the kernel to do something privileged | [System Calls](../../operating-systems/system-calls/) |
| **Virtual memory** | Giving each process the illusion of its own large, private address space | [Virtual Memory](../../operating-systems/virtual-memory/) |
| **NP-complete** | A hard class of problems: solutions are easy to check, and no fast way to find them is known | [P vs NP](../../theory/p-vs-np/) |

| **Foreign key** | A column that refers to another table's primary key | [Relational Model](../../databases/relational-model/) |
