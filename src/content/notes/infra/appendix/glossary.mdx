### Digital Logic

| Term | Meaning | Learn more |
| --- | --- | --- |
| **Transistor** | An electrically controlled switch; billions of them make up a chip | [Transistor Switches](../../digital-logic/transistors-as-switches/) |
| **CMOS** | The chip technology that pairs n-type and p-type transistors so a gate draws current mainly while switching | [CMOS Gates](../../digital-logic/logic-gates-from-transistors/) |
| **Logic gate** | A circuit computing a Boolean function such as AND, OR, NOT, NAND | [CMOS Gates](../../digital-logic/logic-gates-from-transistors/) |
| **Combinational circuit** | A circuit whose output depends only on its current inputs, such as an adder or multiplexer | [Combinational Circuits](../../digital-logic/combinational-circuits/) |
| **Flip-flop / latch** | A circuit that stores one bit; a flip-flop changes only on a clock edge | [Sequential Circuits](../../digital-logic/sequential-circuits/) |
| **Register** | A small group of flip-flops holding one word inside the CPU | [Sequential Circuits](../../digital-logic/sequential-circuits/) |
| **Clock** | The periodic signal that sets when flip-flops update; its frequency is in GHz | [Clocks & Timing](../../digital-logic/clock-signals-and-synchronous-design/) |
| **Critical path** | The slowest path through logic between two flip-flops; it limits the clock frequency | [Clocks & Timing](../../digital-logic/clock-signals-and-synchronous-design/) |
| **FSM** | Finite state machine: state register plus logic choosing the next state | [Hardware FSMs](../../digital-logic/finite-state-machines-in-hardware/) |
| **TDP** | Thermal design power: the sustained heat a cooler must remove, in watts | [Power & Thermals](../../digital-logic/power-and-thermals/) |
| **Dynamic power** | Power spent switching transistors, roughly proportional to capacitance × voltage² × frequency | [Power & Thermals](../../digital-logic/power-and-thermals/) |
| **Process node** | A manufacturing generation, named in nanometres that no longer match any physical size | [Chip Design](../../digital-logic/vlsi-design-basics/) |

### Memory Hierarchy

| Term | Meaning | Learn more |
| --- | --- | --- |
| **Memory hierarchy** | Layers from registers to DRAM, each larger, slower and cheaper per byte than the one above | [Memory Hierarchy](../../memory-hierarchy/why-the-memory-hierarchy-exists/) |
| **Cache line** | The 64-byte block that caches load and store as a unit | [Cache Basics](../../memory-hierarchy/cache-basics/) |
| **Hit / miss** | The requested data was / was not in the cache | [Cache Basics](../../memory-hierarchy/cache-basics/) |
| **Set-associative** | Each address may go in any of a few slots (ways) of one set | [Cache Basics](../../memory-hierarchy/cache-basics/) |
| **Compulsory / capacity / conflict miss** | First touch / working set too big / too many lines mapping to one set | [Cache Basics](../../memory-hierarchy/cache-basics/) |
| **Write-back** | A write updates only the cache; the line goes to memory when evicted | [Cache Basics](../../memory-hierarchy/cache-basics/) |
| **LRU** | Least recently used: evict the line untouched for longest | [Cache Replacement](../../memory-hierarchy/cache-replacement-policies/) |
| **Coherence** | Keeping all cached copies of one address consistent across cores | [Cache Coherence](../../memory-hierarchy/cache-coherence/) |
| **MESI** | The coherence protocol states: Modified, Exclusive, Shared, Invalid | [Cache Coherence](../../memory-hierarchy/cache-coherence/) |
| **False sharing** | Threads writing different variables on the same line, forcing it to bounce | [Cache-Friendly Code](../../memory-hierarchy/cache-friendly-code/) |
| **SRAM** | Static RAM: six transistors per bit, fast, used for caches | [Main Memory](../../memory-hierarchy/main-memory/) |
| **DRAM** | Dynamic RAM: one capacitor per bit, dense, must be refreshed; main memory | [Main Memory](../../memory-hierarchy/main-memory/) |
| **Row buffer** | The open DRAM row; reads from it are fast row hits | [Main Memory](../../memory-hierarchy/main-memory/) |
| **CAS latency (CL)** | Cycles from a column read command to data; convert to ns with CL × 2000 ÷ MT/s | [Main Memory](../../memory-hierarchy/main-memory/) |
| **HBM** | High bandwidth memory: stacked DRAM beside a GPU with a 1024-bit interface | [Main Memory](../../memory-hierarchy/main-memory/) |
| **ECC** | Extra bits that let memory correct single-bit errors and detect double-bit ones | [Main Memory](../../memory-hierarchy/main-memory/) |
| **Memory controller** | The on-chip unit that maps addresses to DRAM and schedules commands | [Memory Controllers](../../memory-hierarchy/memory-controllers/) |
| **Channel** | An independent data path to memory; more channels, more bandwidth | [Memory Controllers](../../memory-hierarchy/memory-controllers/) |
| **NUMA** | Non-uniform memory access: memory attached to another socket is slower | [Memory Controllers](../../memory-hierarchy/memory-controllers/) |
| **MMU** | Memory management unit: translates virtual addresses to physical ones | [TLBs & Paging](../../memory-hierarchy/virtual-memory-at-the-hardware-level/) |
| **TLB** | Translation lookaside buffer: a cache of recent address translations | [TLBs & Paging](../../memory-hierarchy/virtual-memory-at-the-hardware-level/) |
| **Page walk** | Reading the page-table levels to translate an address after a TLB miss | [TLBs & Paging](../../memory-hierarchy/virtual-memory-at-the-hardware-level/) |
| **Huge page** | A 2 MiB or 1 GiB page; one TLB entry covers much more memory | [TLBs & Paging](../../memory-hierarchy/virtual-memory-at-the-hardware-level/) |
| **Prefetching** | Loading lines before they are requested to hide latency | [Prefetching](../../memory-hierarchy/prefetching/) |
| **Persistent memory** | Byte-addressable memory that keeps data without power | [Non-Volatile Memory](../../memory-hierarchy/non-volatile-memory-technologies/) |
| **CXL** | Compute Express Link: a coherent link over PCIe wiring, used to add memory | [Non-Volatile Memory](../../memory-hierarchy/non-volatile-memory-technologies/) |
| **Store buffer** | A per-core queue where stores wait before reaching the cache | [Memory Ordering](../../memory-hierarchy/memory-ordering/) |
| **Fence (barrier)** | An instruction that stops memory operations from being reordered across it | [Memory Ordering](../../memory-hierarchy/memory-ordering/) |
| **CAS** | Compare-and-swap: write only if the location still holds the expected value, atomically | [Memory Ordering](../../memory-hierarchy/memory-ordering/) |

| **SAN / NAS** | Block storage over a network vs file storage over a network | [SAN & NAS](../../storage/storage-area-networks/) |

<Callout type="pitfall">
Several terms mean different things in different layers. A **kernel** is the core of an operating system in CS notes but a function launched on a GPU here; a **page** is 4 KiB of virtual memory but also the read unit inside a flash chip; a **channel** is a memory channel, a PCIe lane group or a radio frequency depending on the note. Check the group before assuming the meaning.
</Callout>
