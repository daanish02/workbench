### Greek letters

| Letter | Name | Typical use |
|---|---|---|
| $\alpha, \beta$ | alpha, beta | significance level, prior parameters, momentum |
| $\gamma$ | gamma | discount, step size in some texts |
| $\delta$, $\Delta$ | delta | small change, difference |
| $\varepsilon$ | epsilon | small tolerance in limits |
| $\eta$ | eta | learning rate, step size |
| $\theta$ | theta | parameter, angle |
| $\lambda$ | lambda | eigenvalue, Lagrange multiplier, rate |
| $\mu$, $\sigma$ | mu, sigma | mean, standard deviation |
| $\pi$ | pi | circle constant, or a stationary distribution in Markov chains |
| $\rho$ | rho | correlation, a fraction in the Adam update |
| $\varphi$ | phi | Euler's totient, golden ratio |
| $\omega$ | omega | angular frequency |
| $\Sigma$, $\sigma$ | capital and small sigma | sum (large), standard deviation or singular value (small) |

</FilterTable>

<Callout type="pitfall">
The same letter can mean different things in different notes. $\pi$ is the circle constant in geometry and a stationary distribution in Markov chains, and $\sigma$ is a standard deviation in probability and a singular value in linear algebra. When in doubt, the note in which the symbol appears defines it.
</Callout>
