### Probability

| Term | Meaning | Note |
|---|---|---|
| **Bayes' rule** | $P(A\mid B) = P(B\mid A)P(A)/P(B)$, reversing a conditional | [Bayes' rule](/workbench/math/probability/bayes-rule/) |
| **Covariance** | $E[XY] - E[X]E[Y]$, how two variables move together | [Joint distributions](/workbench/math/probability/joint-and-conditional-distributions/) |
| **Expectation** | the probability-weighted average of a random variable | [Expectation and variance](/workbench/math/probability/expectation-and-variance/) |
| **Independence** | $P(A \cap B) = P(A)P(B)$; knowing one tells nothing about the other | [Joint distributions](/workbench/math/probability/joint-and-conditional-distributions/) |
| **Markov chain** | a process whose next state depends only on the current one | [Markov chains](/workbench/math/probability/markov-chains/) |
| **Standard deviation** | the square root of the variance, in the same units as the data | [Expectation and variance](/workbench/math/probability/expectation-and-variance/) |
| **Uncorrelated** | zero covariance; weaker than independent | [Joint distributions](/workbench/math/probability/joint-and-conditional-distributions/) |
| **Variance** | $E[(X-\mu)^2]$, the average squared deviation from the mean | [Expectation and variance](/workbench/math/probability/expectation-and-variance/) |

<Callout type="pitfall">
Covariance zero does not mean independence, and a singular value is not an eigenvalue unless the matrix is symmetric positive semidefinite. Check the definition in the linked note when a result depends on the difference.
