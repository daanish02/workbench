A [point estimate](../estimation/) such as a sample mean is a single number, and it is almost never exactly right. A confidence interval reports the estimate together with its uncertainty: a range that the data support. The phrase '95 percent confidence' is widely misread, so this note builds the interval, checks its coverage by simulation, and states what the number does and does not say.

## Building the interval

Suppose the population has standard deviation $\sigma$ and we take a sample of size $n$ with mean $\bar x$. By the central limit theorem the sample mean is approximately normal with standard error $\sigma/\sqrt{n}$. Then $\bar x \pm 1.96\,\sigma/\sqrt{n}$ covers the true mean with probability about $0.95$, because $95\%$ of a normal lies within $1.96$ standard deviations of its centre.

```python
import math

sigma, n, xbar = 2.0, 25, 10.4
half = 1.96 * sigma / math.sqrt(n)
print("95% interval:", round(xbar - half, 3), "to", round(xbar + half, 3))  # prints: 95% interval: 9.616 to 11.184
```

In words: the interval is $10.4 \pm 0.784$, from $9.616$ to $11.184$. Its width is set by $\sigma$, $n$ and the confidence level, not by anything we learned from the particular sample.

## Coverage by simulation

The promise of $95\%$ is about the procedure, and simulation shows it directly. The script below draws $10000$ samples of size $25$ from a normal with mean $0$ and $\sigma = 2$, builds an interval for each, and counts how many contain $0$.

```python
import math
import random

random.seed(9)
mu, sigma, n, reps = 0.0, 2.0, 25, 10000
half = 1.96 * sigma / math.sqrt(n)
covered = 0
for _ in range(reps):
    xbar = sum(random.gauss(mu, sigma) for _ in range(n)) / n
    if xbar - half <= mu <= xbar + half:
        covered += 1
print("share of intervals containing the true mean:", round(covered / reps, 3))  # prints: share of intervals containing the true mean: 0.95
```

In words: about $95\%$ of the intervals contain the true mean, close to the target. The simulation also shows that the other $5\%$ are simply missed, without any sign in the individual interval. Each one looks as reasonable as the rest.

## When the standard deviation is unknown

In practice $\sigma$ is estimated by the sample standard deviation $s$, and for small $n$ the normal critical value $1.96$ is too small. The $t$ distribution with $n - 1$ degrees of freedom replaces it, and its critical value is larger for small samples. For $n = 25$ the $t$ value is about $2.06$, against $1.96$ from the normal.

```python
from scipy import stats

z = stats.norm.ppf(0.975)                      # two-sided 95%: 2.5% in each tail
for n in (5, 25, 100):
    t = stats.t.ppf(0.975, df=n - 1)
    print(f"n = {n:>3}: t critical {t:.4f} vs normal {z:.4f}, width ratio {t / z:.3f}")
# n =   5: t critical 2.7764 vs normal 1.9600, width ratio 1.417
# n =  25: t critical 2.0639 vs normal 1.9600, width ratio 1.053
# n = 100: t critical 1.9842 vs normal 1.9600, width ratio 1.012
```

In words: for $n = 25$ the $t$ value is $2.0639$ and the interval is about $5\%$ wider than the normal one. With only five observations it is $42\%$ wider, and by $n = 100$ the gap is about $1\%$, because the $t$ distribution approaches the normal. `scipy.stats.t.ppf` replaces the printed $t$ table; run it with `uv run --with scipy`.

<Callout type="pitfall">
Do not say 'there is a $95\%$ chance the true mean lies in this interval'. Once the data are fixed the interval either contains the mean or it does not. The probability belongs to the method, which captures the truth in $95\%$ of repeated samples.
</Callout>

## Width and sample size

The width is $2 \times 1.96\,\sigma/\sqrt{n}$. To halve it you need four times as many observations, which is why precise estimates are expensive. Planning a study means choosing $n$ so that the expected width is small enough to answer the question.
