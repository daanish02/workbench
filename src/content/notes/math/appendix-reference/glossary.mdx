### Foundations

| Term | Meaning | Note |
|---|---|---|
| **Bijection** | a function that is both injective and surjective, so it has an inverse | [Functions](/workbench/math/foundations/functions/) |
| **Binomial coefficient** | $\binom{n}{k}$, the number of ways to choose $k$ of $n$ items ignoring order | [Combinatorics](/workbench/math/foundations/combinatorics/) |
| **Alpha-cut** | the crisp set of elements whose membership degree is at least $\alpha$ | [Fuzzy logic](/workbench/math/foundations/fuzzy-logic/) |
| **Cardinality** | the number of elements of a set | [Sets](/workbench/math/foundations/sets/) |
| **Contrapositive** | $\lnot q \to \lnot p$, logically equivalent to $p \to q$ | [Propositional logic](/workbench/math/foundations/propositional-logic/) |
| **Convergence** | a sequence or series approaches a limit as its index grows | [Sequences and series](/workbench/math/foundations/sequences-and-series/) |
| **Defuzzification** | reducing a fuzzy output set to one number, usually its centroid | [Fuzzy logic](/workbench/math/foundations/fuzzy-logic/) |
| **Floating point** | a number stored as a fixed count of significant bits times a power of two | [Number systems](/workbench/math/foundations/number-systems/) |
| **Fuzzy set** | a set given by a membership function $\mu : X \to [0, 1]$, a degree of belonging per element | [Fuzzy logic](/workbench/math/foundations/fuzzy-logic/) |
| **Induction** | proving $P(n)$ for all $n$ from a base case and a step $P(k) \Rightarrow P(k+1)$ | [Proof techniques](/workbench/math/foundations/proof-techniques/) |
| **Injective** | no two inputs share an output (one-to-one) | [Functions](/workbench/math/foundations/functions/) |
| **Machine epsilon** | the gap between $1$ and the next float, about $2.2 \times 10^{-16}$ for doubles | [Number systems](/workbench/math/foundations/number-systems/) |
| **Modulus (complex)** | the distance $\lvert z \rvert$ of a complex number from the origin | [Complex numbers](/workbench/math/foundations/complex-numbers/) |
| **Permutation** | an ordered selection; $P(n, k) = n!/(n-k)!$ of them | [Combinatorics](/workbench/math/foundations/combinatorics/) |
| **Power set** | the set of all subsets; $2^n$ of them for an $n$-element set | [Sets](/workbench/math/foundations/sets/) |
| **Radian** | the angle that cuts an arc equal to the radius; $2\pi$ radians make a full turn | [Trigonometry](/workbench/math/foundations/trigonometry/) |
| **Surjective** | every element of the codomain is an output (onto) | [Functions](/workbench/math/foundations/functions/) |
| **Tautology** | a formula true under every assignment | [Propositional logic](/workbench/math/foundations/propositional-logic/) |

|---|---|---|

| **Span** | all linear combinations of a set of vectors | [Vectors](/workbench/math/linear-algebra/vectors/) |
| **Tensor order** | the number of indices of an array, NumPy's `ndim` | [Tensors](/workbench/math/linear-algebra/tensors/) |
