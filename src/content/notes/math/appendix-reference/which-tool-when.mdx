## Two tools in sequence

- **Model, then fit.** Write the data-generating process as a distribution, then estimate its parameters by maximum likelihood (estimation).
- **Set up, then solve.** Write the objective and constraints (constrained optimisation), then find the optimum with a method that fits the structure (linear programming or gradient descent).
- **Transform, then analyse.** Move the signal to the frequency domain (Fourier), filter there, and invert.

<Callout type="pitfall">
A tool that gives a clean answer on the wrong model is still wrong. Before trusting a p-value, a regression slope or a spectrum, check the assumptions it needs: independence, a finite variance, a linear relation, or a sampling rate above twice the highest frequency.
</Callout>
