Many of the structures in discrete mathematics share the same few rules: an operation that combines two things, a way to undo it, and a rule about how the operations interact. Abstract algebra names these structures and studies them without caring what the elements are. That generality is the point: the same proof works for clock arithmetic, permutations, polynomials and bit strings. This note defines groups, rings and fields, and checks the axioms by computer on small finite examples.

## Groups

A group $(G, \ast)$ is a set with a binary operation satisfying four axioms: closure, associativity, an identity $e$ with $e \ast g = g$, and an inverse for every $g$. The integers mod $n$ under addition are a group. The check below verifies the axioms for $\mathbb{Z}_{12}$.

```python
n = 12
G = range(n)
op = lambda a, b: (a + b) % n
closed = all(op(a, b) in G for a in G for b in G)
assoc = all(op(op(a, b), c) == op(a, op(b, c)) for a in G for b in G for c in G)
identity = all(op(0, a) == a and op(a, 0) == a for a in G)
inverses = all(any(op(a, b) == 0 for b in G) for a in G)
print("closed, associative, identity, inverses:", closed, assoc, identity, inverses)  # prints: closed, associative, identity, inverses: True True True True
```

In words: addition mod $12$ satisfies all four axioms. The identity is $0$, and the inverse of $a$ is $12 - a$ (or $0$ for $a = 0$).

Groups need not be commutative. The permutations of three objects form a group of six elements, and composing permutations depends on order. The script below counts them and checks that composition is not always commutative.

```python
from itertools import permutations

S3 = list(permutations(range(3)))
compose = lambda p, q: tuple(p[q[i]] for i in range(3))
print("size of S3:", len(S3))  # prints: size of S3: 6
print("composition commutes for all pairs:", all(compose(p, q) == compose(q, p) for p in S3 for q in S3))  # prints: composition commutes for all pairs: False
```

In words: there are six permutations, and they do not commute in general. The group $S_3$ is the smallest non-commutative group, and it appears wherever symmetries are counted.

## Rings and fields

A ring has two operations, addition forming a commutative group and multiplication associative with distributivity. The integers mod $n$ form a ring. A field is a commutative ring in which every nonzero element has a multiplicative inverse. The check below asks which elements of $\mathbb{Z}_n$ have inverses for a prime and a composite modulus.

```python
def invertible(n):
    return [a for a in range(1, n) if any((a * b) % n == 1 for b in range(1, n))]

print("units mod 7:", invertible(7), " all nonzero elements invertible:", len(invertible(7)) == 6)  # prints: units mod 7: [1, 2, 3, 4, 5, 6] all nonzero elements invertible: True
print("units mod 6:", invertible(6), " all nonzero elements invertible:", len(invertible(6)) == 5)  # prints: units mod 6: [1, 5] all nonzero elements invertible: False
```

In words: mod $7$ every nonzero element is invertible, so $\mathbb{Z}_7$ is a field. Mod $6$ only $1$ and $5$ are invertible, so $\mathbb{Z}_6$ is a ring but not a field. Mod $6$ also $2 \cdot 3 = 0$, which a field cannot do.

<Callout type="pitfall">
Do not assume that a structure is a field because it has addition, multiplication and most of the familiar rules. The decisive property is that every nonzero element has an inverse, and integers mod a composite number usually fail it. That is exactly why the modular inverse in RSA exists only when the gcd condition holds.
</Callout>

## Why it matters

Finite fields underlie error-correcting codes, secret sharing and the arithmetic of elliptic-curve cryptography. Groups describe symmetry, and the discrete logarithm problem of the cryptography note is a statement about the group structure of the integers mod a prime.
