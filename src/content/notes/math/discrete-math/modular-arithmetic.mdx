Modular arithmetic is arithmetic on a clock. Adding five hours to ten o'clock gives three, not fifteen, because the clock wraps around. The same idea, applied to the integers with a fixed modulus $n$, underlies hash functions, error-detecting codes, random number generators and public-key cryptography. This note sets up congruences, explains when a division is possible, and states the two theorems that make modular exponentiation useful.

## Congruences and the clock

Write $a \equiv b \pmod n$ when $n$ divides $a - b$. Congruence is compatible with addition and multiplication: if $a \equiv a'$ and $b \equiv b'$, then $a + b \equiv a' + b'$ and $ab \equiv a'b'$. So you can reduce modulo $n$ at any step without changing the final answer.

On a clock $n = 12$. The script below checks that reducing early gives the same result as reducing at the end.

```python
n = 12
a, b = 10, 7
print("(10 + 7) mod 12 =", (a + b) % n, " (10 mod 12 + 7 mod 12) mod 12 =", (a % n + b % n) % n)  # prints: (10 + 7) mod 12 = 5 (10 mod 12 + 7 mod 12) mod 12 = 5
x = 3 * 3 * 3 * 3 * 3
r = 1
for _ in range(5):
    r = r * 3 % 12  # reduce after every multiplication
print("3^5 =", x, " mod 12 =", x % 12, " reduced at each step:", r)  # prints: 3^5 = 243 mod 12 = 3 reduced at each step: 3
```

In words: ten hours plus seven hours is five on the clock, whichever way you reduce. The power example shows the same thing: $3^5 = 243 \equiv 3 \pmod{12}$ no matter when the reduction happens.

## Modular inverses

Division modulo $n$ means multiplying by an inverse. The inverse of $a$ exists exactly when $\gcd(a, n) = 1$. For $n = 12$, the numbers $5$ and $7$ are invertible, but $4$ and $6$ are not. The check below finds every inverse by brute force.

```python
from math import gcd

n = 12
for a in range(1, n):
    inv = [x for x in range(1, n) if (a * x) % n == 1]
    print(f"a = {a:>2}: gcd = {gcd(a, n)}, inverse = {inv[0] if inv else 'none'}")  # prints: a =  1: gcd = 1, inverse = 1
```

In words: $5 \cdot 5 = 25 \equiv 1 \pmod{12}$, so $5$ is its own inverse, and $7 \cdot 7 = 49 \equiv 1$. The numbers with a common factor with $12$ have no inverse, because multiplying them can never reach $1$.

## Fermat's little theorem

For a prime $p$ and $a$ not divisible by $p$, $a^{p-1} \equiv 1 \pmod p$. Equivalently, $a^{p-2}$ is the inverse of $a$. The check below tests this for $p = 13$ and all $a$ from $1$ to $12$.

```python
p = 13
print("all a^(p-1) = 1 mod p:", all(pow(a, p - 1, p) == 1 for a in range(1, p)))  # prints: all a^(p-1) = 1 mod p: True
print("inverse of 5 mod 13 via a^(p-2):", pow(5, p - 2, p), " check 5 * that mod 13 =", (5 * pow(5, p - 2, p)) % p)  # prints: inverse of 5 mod 13 via a^(p-2): 8 check 5 * that mod 13 = 1
```

In words: every nonzero residue raised to the power $12$ is $1$ modulo $13$, and $8$ is the inverse of $5$ because $40 = 3 \cdot 13 + 1$. The power $a^{p-2}$ gives inverses without the extended Euclidean algorithm, which is useful when $p$ is fixed.

## Fast modular exponentiation

Computing $a^k \bmod n$ by multiplying $a$ by itself $k$ times is hopeless when $k$ has hundreds of digits. **Square-and-multiply** reads the bits of $k$ instead: squaring the running power doubles the exponent, and multiplying by $a$ adds one. Every intermediate value is reduced mod $n$, so the numbers never grow.

```python
def power_mod(a, k, n):
    result, base, steps = 1, a % n, 0
    while k:
        if k & 1:                      # this bit of k is set: multiply it in
            result = result * base % n
            steps += 1
        base = base * base % n         # move to the next bit: square
        steps += 1
        k >>= 1
    return result, steps

value, steps = power_mod(7, 560, 561)
print("7^560 mod 561 =", value, " multiplications:", steps, " built-in pow:", pow(7, 560, 561))
# 7^560 mod 561 = 1  multiplications: 13  built-in pow: 1
```

In words: $560$ in binary has ten bits, so the loop squares ten times and multiplies three times, $13$ multiplications instead of $559$. The cost grows with the number of digits of $k$, about $2\log_2 k$ multiplications at most, which is what makes RSA and Diffie–Hellman practical. Python's three-argument `pow` does the same.

## The Chinese remainder theorem

If $n_1$ and $n_2$ are coprime, the pair of remainders $(x \bmod n_1, x \bmod n_2)$ determines $x \bmod n_1 n_2$, and every pair occurs exactly once. So a system of congruences

$$
x \equiv a_1 \pmod{n_1}, \qquad x \equiv a_2 \pmod{n_2}

$$

has exactly one solution modulo $n_1 n_2$. The construction uses inverses: $x = a_1 M_1 y_1 + a_2 M_2 y_2$, where $M_1 = n_2$, $M_2 = n_1$, and $y_i$ is the inverse of $M_i$ modulo $n_i$.

```python
def crt(a1, n1, a2, n2):
    y1, y2 = pow(n2, -1, n1), pow(n1, -1, n2)   # inverses exist because gcd(n1, n2) = 1
    return (a1 * n2 * y1 + a2 * n1 * y2) % (n1 * n2)

x = crt(2, 3, 3, 5)
print("x = 2 mod 3 and x = 3 mod 5 gives x =", x, " check:", x % 3, x % 5)
print("each x mod 15 has a distinct pair:", len({(x % 3, x % 5) for x in range(15)}) == 15)
# x = 2 mod 3 and x = 3 mod 5 gives x = 8  check: 2 3
# each x mod 15 has a distinct pair: True
```

In words: $8$ leaves remainder $2$ on division by $3$ and $3$ on division by $5$, and it is the only such number below $15$. All fifteen residues give different pairs, which is the theorem. Libraries use this to speed up RSA decryption, by working mod $p$ and mod $q$ separately and combining the results.

## Euler's totient

For a general modulus, $\varphi(n)$ counts the integers from $1$ to $n$ that are coprime to $n$. Euler's theorem says $a^{\varphi(n)} \equiv 1 \pmod n$ whenever $\gcd(a, n) = 1$.

```python
from math import gcd

n = 12
phi = sum(1 for k in range(1, n + 1) if gcd(k, n) == 1)
print("phi(12) =", phi, " check 5^phi mod 12 =", pow(5, phi, n))  # prints: phi(12) = 4 check 5^phi mod 12 = 1
```

In words: four numbers up to $12$ are coprime to it, namely $1, 5, 7, 11$. Euler's theorem then says $5^4 \equiv 1 \pmod{12}$, which the check confirms.

<Callout type="pitfall">
Modular arithmetic does not behave like ordinary division. In $\mathbb{Z}_{12}$, $2 \cdot 6 = 12 \equiv 0$, so two nonzero numbers can multiply to zero. Cancelling a common factor from both sides of a congruence requires that factor to be coprime to the modulus.
</Callout>

## Why it matters

Fast modular exponentiation, the inverses and the two theorems above are the ingredients of RSA. The cryptography note combines them into a complete scheme with a worked example.
