Graphs model anything made of objects and connections between them: friendships, road networks, dependencies between software modules, links between web pages. They are the basic objects of discrete mathematics, and most of the algorithms in the next note work on them. This note fixes the vocabulary, proves the handshake identity, and shows the adjacency matrix counting walks.

## Vertices, edges and directions

A graph $G = (V, E)$ has a set of vertices $V$ and a set of edges $E$. In an undirected graph an edge $\{u, v\}$ joins two vertices with no direction; in a directed graph $(u, v)$ points from $u$ to $v$. Multiple edges and loops are excluded here.

The complete graph $K_n$ has every pair of $n$ vertices joined, so it has $\binom{n}{2}$ edges. The script below builds $K_4$ and checks the count.

```python
from itertools import combinations

n = 4
V = list(range(n))
E = list(combinations(V, 2))
print("edges in K_4:", len(E), " formula n(n-1)/2:", n * (n - 1) // 2)
# edges in K_4: 6  formula n(n-1)/2: 6
```

In words: four vertices can be joined in six ways. Every pair is an edge, so the count matches the formula.

## Degrees and the handshake lemma

The degree $\deg(v)$ is the number of edges at $v$. Each edge has two ends, so summing the degrees counts every edge twice:

$$
\sum_{v \in V} \deg(v) = 2|E|.
$$

In particular the number of odd-degree vertices is always even. The script checks this on a small graph: a square with a diagonal.

```python
edges = [(0, 1), (1, 2), (2, 3), (3, 0), (0, 2)]
deg = [0] * 4
for u, v in edges:
    deg[u] += 1
    deg[v] += 1
print("degrees:", deg, " sum:", sum(deg), " 2|E| =", 2 * len(edges))
# degrees: [3, 2, 3, 2]  sum: 10  2|E| = 10
```

In words: the degrees $3, 2, 3, 2$ sum to $10 = 2 \times 5$. Vertices $0$ and $2$ are the ones on the diagonal, which is why they have degree three.

## Paths, cycles and connectivity

A path is a sequence of distinct vertices with an edge between each consecutive pair. A cycle is a path that returns to its first vertex. A graph is connected when every two vertices are joined by a path. Trees are connected graphs with no cycles, and they have exactly $|V| - 1$ edges.

The square above has the cycle $0, 1, 2, 3, 0$. Removing any one edge keeps it connected, but removing the two edges at vertex $1$ cuts that vertex off. An edge whose removal disconnects a graph is a **bridge**; this graph has none, while every edge of a tree is one.

## Adjacency matrices and walks

The adjacency matrix $A$ records each edge. For the square with a diagonal, $A_{ij} = 1$ when $i$ and $j$ are joined. The entry $(A^2)_{ij}$ counts walks of length two from $i$ to $j$, since each middle step is an edge.

```python
edges = [(0, 1), (1, 2), (2, 3), (3, 0), (0, 2)]  # the square with a diagonal, from above
A = [[0] * 4 for _ in range(4)]
for u, v in edges:
    A[u][v] = A[v][u] = 1
A2 = [[sum(A[i][k] * A[k][j] for k in range(4)) for j in range(4)] for i in range(4)]
print("diagonal of A^2 (equals the degrees):", [A2[i][i] for i in range(4)])
print("walks of length 2 from 1 to 3:", A2[1][3])
# diagonal of A^2 (equals the degrees): [3, 2, 3, 2]
# walks of length 2 from 1 to 3: 2
```

In words: the diagonal of $A^2$ gives back the degrees, because a walk of length two that starts and ends at $v$ goes out along an edge and back. There are two walks from $1$ to $3$, through $0$ and through $2$.

<Callout type="pitfall">
In a directed graph the degree splits into in-degree and out-degree, and the handshake identity becomes the sum of in-degrees equals the sum of out-degrees, both equal to $|E|$. Do not apply the undirected formula $2|E|$ to a directed graph.
</Callout>

## Checking with a library

NetworkX builds the same graph and answers the same questions, which makes a quick independent check of hand calculations:

```python
import networkx as nx
import numpy as np

G = nx.Graph([(0, 1), (1, 2), (2, 3), (3, 0), (0, 2)])
print("degrees:", dict(G.degree()), " sum = 2|E|:", sum(d for _, d in G.degree()) == 2 * G.number_of_edges())
A = nx.to_numpy_array(G, nodelist=range(4), dtype=int)
print("walks of length 2 from 1 to 3:", np.linalg.matrix_power(A, 2)[1, 3])
print("bridges:", list(nx.bridges(G)), " connected:", nx.is_connected(G))
# degrees: {0: 3, 1: 2, 2: 3, 3: 2}  sum = 2|E|: True
# walks of length 2 from 1 to 3: 2
# bridges: []  connected: True
```

In words: the library agrees with the degrees, the walk count and the claim that no single edge disconnects the graph. Run it with `uv run --with networkx --with numpy`.

## Why graphs matter

Almost every problem about relationships reduces to a graph question: reachability, shortest routes, scheduling with dependencies, colouring for conflicts. The vocabulary here is what the algorithms in the next note rely on.
