Exponentials and logarithms describe change that compounds. Savings accounts, populations, radioactive decay, and the number of steps in a binary search all follow them. This note defines both functions, shows that they are inverses of each other, and lists the laws you need to rearrange formulas. Every later section that talks about growth, from probability to deep learning's loss curves, assumes these laws.

## Exponentials

For a base $b > 0$, $b^{x}$ is defined first for whole numbers as repeated multiplication, then extended to fractions and reals. Three behaviours matter:

- $b^{0} = 1$ for any nonzero $b$, because $b^{x} / b^{x} = b^{x-x} = b^{0}$ and anything divided by itself is 1.
- $b^{x+y} = b^{x} \cdot b^{y}$: adding exponents multiplies powers.
- $b > 1$ gives growth; $0 < b < 1$ gives decay.

The special base is $e \approx 2.71828$, the base $b$ for which $b^x$ is its own derivative. $e^{x}$ grows at a rate equal to its current value, which is why it describes continuous compounding. Any other base can be written as $b^{x} = e^{x \ln b}$.

## Logarithms

The logarithm is the inverse of the exponential. $\log_b(y) = x$ means $b^{x} = y$. Read it as "the power of $b$ that gives $y$". Two identities hold for all valid inputs:

- $\log_b(b^{x}) = x$
- $b^{\log_b y} = y$

The natural logarithm $\ln x = \log_e x$ is the one used in calculus. The base 2 logarithm $\log_{2}$ counts doublings, and base 10 counts digits.

## Laws

These rules follow from the exponent laws and let you rearrange any formula:

| Law | Statement | Why |
| --- | --- | --- |
| Product | $\log(ab) = \log a + \log b$ | $b^{x} b^{y} = b^{x+y}$ |
| Power | $\log(a^{p}) = p \log a$ | $(b^{x})^{p} = b^{xp}$ |
| Quotient | $\log(a/b) = \log a - \log b$ | division is multiplication by the reciprocal |
| Change of base | $\log_b y = (\log y) / (\log b)$ | writes any base in terms of one fixed base |

The script below checks that exponential and logarithm undo each other, verifies the product and power laws, and uses change of base to compute $\log_{2}$.

```python
import math

for x in [0.5, 1, 10, 1000]:
    print(f"x={x:>6}: exp(log(x)) = {math.exp(math.log(x)):.6f}")

a, b = 8.0, 32.0
print("log(ab) == log a + log b:", math.isclose(math.log(a * b), math.log(a) + math.log(b)))
print("log(a^3) == 3 log a:", math.isclose(math.log(a ** 3), 3 * math.log(a)))
print("log2(32) =", math.log2(32), " via natural log:", math.log(32) / math.log(2))
# x=   0.5: exp(log(x)) = 0.500000
# x=     1: exp(log(x)) = 1.000000
# x=    10: exp(log(x)) = 10.000000
# x=  1000: exp(log(x)) = 1000.000000
# log(ab) == log a + log b: True
# log(a^3) == 3 log a: True
# log2(32) = 5.0  via natural log: 5.0
```

In words: $\exp$ followed by $\log$ returns the input, so the two are inverses on positive numbers. The product law says the log of a product is a sum, which is the reason slide rules work. Change of base gives $\log_{2}(32) = \ln 32 / \ln 2 = 5$, the same answer `math.log2` returns directly.

<Callout type="pitfall">
$\log(x)$ is undefined for $x \le 0$, and $\log(a + b)$ does not equal $\log a + \log b$. The product law applies only to products inside the log. Dropping the parentheses is the most common algebra error with logs.
</Callout>

## Growth and doubling

Continuous growth at rate $r$ gives $A(t) = A_{0} e^{rt}$. The doubling time $T$ satisfies $e^{rT} = 2$, so $T = \ln 2 / r$. The number $\ln 2$ is about $0.693$, so at 7% the doubling time is about 9.9 years. The **rule of 72** says $72 / (\text{rate in percent})$ gives roughly the same answer for annual compounding, and it is accurate enough to be useful.

```python
import math

r = 0.07
print("years to double at 7% continuous growth:", round(math.log(2) / r, 2))  # prints: years to double at 7% continuous growth: 9.9
print("annual compounding at 7%:", round(math.log(2) / math.log(1.07), 2))  # prints: annual compounding at 7%: 10.24
print("rule of 72 estimate:", round(72 / 7, 2))  # prints: rule of 72 estimate: 10.29
```

In words: continuous growth at $7\%$ doubles in $9.9$ years, and annual compounding, $\ln 2 / \ln 1.07$, takes $10.24$ years. The rule of 72 gives $10.29$, close to the annual figure it is designed for. For a quick estimate, the difference matters less than the order of magnitude.

## Logs in computing

A binary search halves the remaining range each step, so it needs $\log_{2} n$ steps for $n$ items. A balanced tree of $n$ nodes has height about $\log_{2} n$. Information is measured in bits, which is $\log_{2}$ of the number of equally likely outcomes. When you see $O(\log n)$ in a complexity analysis, it is the inverse of the exponential growth of doubling, and the [Big-O Cheat Sheet](../../../cs/appendix-reference/big-o-cheat-sheet/) lists the cases.
