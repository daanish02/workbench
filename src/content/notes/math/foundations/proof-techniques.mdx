Some claims can be checked by computer for a thousand cases, and some cannot be checked at all, because they talk about infinitely many numbers. A proof is the tool that settles both. It is a finite argument that leaves no room for a counterexample. This note covers the four techniques that prove most of what the rest of this section needs. They rest on the connectives from [Propositional Logic](../propositional-logic/), so keep that note in mind.

## Direct proof

To prove $p \to q$, assume $p$ and derive $q$, one justified step at a time. Each step has a reason: a definition, an earlier theorem, or an algebra rule.

**Claim:** if $n$ is even, then $n^{2}$ is even.

*Proof.* Assume $n$ is even. Then $n = 2k$ for some integer $k$. So $n^{2} = 4k^{2} = 2(2k^{2})$. Since $2k^{2}$ is an integer, $n^{2}$ is even.

Every step follows from the one before it, and the only assumption used is the hypothesis. Direct proof should be your first try.

## Contraposition

The contrapositive of $p \to q$ is $\lnot q \to \lnot p$. The two are logically equivalent, so proving the contrapositive proves the original. Use it when assuming $\lnot q$ gives you more to work with than assuming $p$.

**Claim:** if $n^{2}$ is even, then $n$ is even.

Direct proof here is awkward. The contrapositive is easier: suppose $n$ is odd, so $n = 2k + 1$. Then $n^{2} = 4k^{2} + 4k + 1 = 2(2k^{2} + 2k) + 1$, which is odd. So if $n^{2}$ is even, $n$ cannot be odd, and therefore $n$ is even.

In words: instead of asking what an even square forces, we ask what an odd number's square looks like, and we find it is always odd.

## Contradiction

To prove a statement $p$, assume $\lnot p$ and derive something false. Since a consistent system cannot contain a falsehood, $p$ must be true. This is the classic route to results that say something does not exist.

**Claim:** $\sqrt 2$ is irrational.

*Proof.* Suppose $\sqrt 2 = a/b$ in lowest terms, with $a$ and $b$ integers and no common factor. Then $a^{2} = 2b^{2}$, so $a^{2}$ is even, so $a$ is even (by contraposition, above). Write $a = 2c$. Then $4c^{2} = 2b^{2}$, so $b^{2} = 2c^{2}$, so $b$ is even too. Now $a$ and $b$ are both even, contradicting "lowest terms".

The script below does not prove the claim; it searches small fractions and finds none whose square is 2. A search is a sanity check, and the proof above is what settles the question for all fractions.

```python
from fractions import Fraction

hits = [Fraction(a, b) for b in range(1, 300) for a in range(1, 500)
        if Fraction(a, b) ** 2 == 2]
print("exact rational solutions found in search:", hits)  # prints: exact rational solutions found in search: []
```

In words: no fraction with numerator below 500 and denominator below 300 squares to exactly 2. That is consistent with the proof, but it is the proof, not the search, that rules out every fraction.

## Induction

Induction proves a statement $P(n)$ for every natural number $n$. Two steps are needed:

1. **Base case:** prove $P(1)$ (or $P(0)$).
2. **Inductive step:** assume $P(k)$ for some $k$, and prove $P(k + 1)$.

If both hold, $P(1)$ gives $P(2)$, which gives $P(3)$, and so on for every $n$. The assumption $P(k)$ is called the **inductive hypothesis**.

**Claim:** the sum of the first $n$ odd numbers is $n^{2}$.

*Proof.* Base case: the first odd number is 1 = 1². Inductive step: assume $1 + 3 + ... + (2k - 1) = k^{2}$. Adding the next odd number, $2k + 1$, gives $k^{2} + (2k + 1) = (k + 1)^{2}$.

The check below confirms the base case and the algebra of the step. It cannot replace the proof, because it only tests finitely many $n$.

```python
def odd_sum(n):
    return sum(2 * k - 1 for k in range(1, n + 1))

print("base case n=1:", odd_sum(1) == 1 ** 2)  # prints: base case n=1: True
print("checked n = 1..50:", all(odd_sum(n) == n * n for n in range(1, 51)))  # prints: checked n = 1..50: True
print("step identity holds for k=0..99:", all(k * k + (2 * k + 1) == (k + 1) ** 2 for k in range(100)))  # prints: step identity holds for k=0..99: True
```

In words: the base case starts the chain, the step makes each link follow from the last, and together they reach every $n$. Induction is also how you reason about loops: a loop invariant is an inductive hypothesis that holds after each iteration.

<Callout type="pitfall">
A common error is to prove the inductive step without using the hypothesis. If $P(k + 1)$ can be shown with no assumption about $P(k)$, the argument is probably proving something that holds for other reasons, or the base case is missing. Always point to the line where $P(k)$ is used.
</Callout>

## Choosing a technique

Start with the hypothesis and try to derive the conclusion. If the conclusion is a negation, or says something does not exist, try contradiction. If the conclusion is an implication whose negation is easy to use, try contraposition. If the statement is indexed by $n$, try induction. Writing down the proof type you intend helps the reader follow the argument, and helps you notice when you have drifted into an unjustified step.
