Many questions reduce to finding unknowns that satisfy several equations together: how much of each ingredient gives a target mix, which currents flow through a circuit, where two planes meet. These are systems of linear equations, and they are the reason matrices were invented. This note shows how to solve one by hand with Gaussian elimination, how to read the answer from the reduced form, and how to tell in advance whether a system has a solution at all.

## Writing a system as a matrix

Take the system

$$
2x + y - z = 8,\qquad -3x - y + 2z = -11,\qquad -2x + y + 2z = -3.
$$

Collect the coefficients into a matrix $A$, the unknowns into $\mathbf{x} = (x, y, z)$, and the right-hand sides into $\mathbf{b}$. The system is $A\mathbf{x} = \mathbf{b}$. The question becomes: which vector $\mathbf{x}$ does $A$ send to $\mathbf{b}$? That is the transformation view from the [Matrices as Transformations](../matrices-as-transformations/) note, now used backwards.

## Gaussian elimination

Elimination uses three moves that do not change the solutions: swap two equations, multiply an equation by a nonzero number, and add a multiple of one equation to another. The goal is a triangular form in which each equation has one fewer unknown than the one above it.

Working on the augmented matrix $[A \mid \mathbf{b}]$ keeps the bookkeeping short. Pick a pivot in each column, use it to clear the entries below, and move to the next column. The script below does this in a loop, then checks the answer with a library solver.

```python
import numpy as np

A = np.array([[2.0, 1.0, -1.0],
              [-3.0, -1.0, 2.0],
              [-2.0, 1.0, 2.0]])
b = np.array([8.0, -11.0, -3.0])

M = np.hstack([A, b.reshape(-1, 1)]).copy()
n = 3
for col in range(n):
    pivot = np.argmax(np.abs(M[col:, col])) + col
    M[[col, pivot]] = M[[pivot, col]]
    for row in range(col + 1, n):
        M[row] -= (M[row, col] / M[col, col]) * M[col]
print("row echelon form:")
print(np.round(M, 3))

x = np.linalg.solve(A, b)
print("solution:", np.round(x, 6))
print("residual max |Ax - b|:", f"{np.max(np.abs(A @ x - b)):.1e}")
```

In words: the loop turns the matrix into a staircase whose last row is $0.2z = -0.2$, so $z = -1$. Back-substitution then gives $y = 3$ and $x = 2$. The solver returns $(2, 3, -1)$, and the residual $A\mathbf{x} - \mathbf{b}$ is at the level of rounding error, so the solution satisfies all three equations.

## Reading the staircase

In row echelon form, each leading nonzero entry (a **pivot**) sits to the right of the pivot above it. Columns with pivots correspond to variables that are determined. Columns without pivots correspond to **free variables**, which can take any value, and the other variables depend on them.

The rank of $A$ is the number of pivots. Three cases follow:

- **Unique solution:** the rank equals the number of unknowns, and the system is consistent.
- **No solution:** a row reads $0 = c$ with $c \neq 0$. The equations contradict each other.
- **Infinitely many solutions:** the rank is smaller than the number of unknowns, and the system is consistent. Free variables parametrise the solutions.

```python
import numpy as np

A = np.array([[2.0, 1.0, -1.0],
              [-3.0, -1.0, 2.0],
              [-2.0, 1.0, 2.0]])
print("rank of A:", np.linalg.matrix_rank(A))

S = np.array([[1.0, 2.0], [2.0, 4.0]])  # the second equation is twice the first
print("rank of singular S:", np.linalg.matrix_rank(S))
```

In words: $A$ has rank $3$, which matches its three unknowns, so the system has exactly one solution. The matrix $S$ has rank $1$, below its two unknowns. Its two equations are the same line, so there are infinitely many solutions, one for each point on that line.

<Callout type="pitfall">
Floating-point elimination can produce a tiny nonzero number where exact arithmetic gives zero. Testing a pivot for equality with zero is unreliable in practice; library routines pick a pivot by size and check the rank with a tolerance.
</Callout>

## Cost and practice

Elimination on an $n \times n$ system takes roughly $\frac{2}{3}n^3$ operations, so doubling the size costs about eight times the work. Library solvers use the same idea, organised as an LU factorisation, which can be reused for many right-hand sides. For large sparse systems, iterative methods are used instead. The idea of a pivot and the rank test are the parts to understand; the rest is engineering.

## Where systems come from

Balancing chemical equations, fitting a line through data points, finding equilibrium in a network of springs, and the linear equations that a neural network's training step solves approximately all reduce to this problem. Learning to read the echelon form is the fastest way to see whether a model is over- or under-determined.
