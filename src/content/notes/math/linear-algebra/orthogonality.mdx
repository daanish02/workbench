Perpendicular axes are the most convenient coordinate system there is. If the axes are at right angles and have unit length, finding the coordinates of a point is a set of dot products, and lengths and distances are just Pythagoras. Orthogonality is the property that makes this work, and it is the reason rotations preserve shape and the reason many numerical algorithms are stable. This note defines orthogonal and orthonormal sets, shows how to build an orthonormal basis from any independent set, and describes orthogonal matrices.

## Orthogonal and orthonormal sets

Two vectors $\mathbf{u}$ and $\mathbf{v}$ are orthogonal when $\mathbf{u}\cdot\mathbf{v} = 0$, which for nonzero vectors means they meet at a right angle. A set of vectors is orthogonal when every pair in it is orthogonal. It is orthonormal when, in addition, each vector has length one. Orthonormal vectors are usually written $\mathbf{q}_1, \mathbf{q}_2, \ldots$.

The payoff is in coordinates. If $\mathbf{q}_1, \ldots, \mathbf{q}_n$ is an orthonormal basis, then any vector $\mathbf{x}$ satisfies

$$
\mathbf{x} = (\mathbf{x}\cdot\mathbf{q}_1)\,\mathbf{q}_1 + \cdots + (\mathbf{x}\cdot\mathbf{q}_n)\,\mathbf{q}_n.

$$

No linear system has to be solved. Each coefficient is a single dot product.

## Gram-Schmidt

Given independent vectors $\mathbf{a}_1, \mathbf{a}_2, \ldots$, Gram-Schmidt builds an orthonormal set one step at a time. Start with $\mathbf{q}_1 = \mathbf{a}_1 / \|\mathbf{a}_1\|$. For each next vector, subtract its components along the vectors already built, then normalise what remains:

$$
\mathbf{w} = \mathbf{a}_k - \sum_{i<k} (\mathbf{a}_k\cdot\mathbf{q}_i)\,\mathbf{q}_i, \qquad \mathbf{q}_k = \frac{\mathbf{w}}{\|\mathbf{w}\|}.

$$

The script below runs the process on three vectors in space and checks that the result is orthonormal.

```python
import numpy as np

def gram_schmidt(vectors):
    basis = []
    for v in vectors:
        w = v.astype(float).copy()
        for q in basis:
            w -= np.dot(q, v) * q
        basis.append(w / np.linalg.norm(w))
    return np.array(basis).T

V = np.array([[1.0, 1.0, 0.0],
              [1.0, 0.0, 1.0],
              [0.0, 1.0, 1.0]])
Q = gram_schmidt(V)
print("columns orthonormal (Q^T Q = I):", np.allclose(Q.T @ Q, np.eye(3)))  # prints: columns orthonormal (Q^T Q = I): True
```

In words: the three input vectors are independent but not perpendicular. After Gram-Schmidt the columns of $Q$ are perpendicular unit vectors, and $Q^\top Q = I$ confirms it. The span has not changed: the new vectors are combinations of the old ones.

## Orthogonal matrices

A square matrix $Q$ is **orthogonal** when $Q^\top Q = I$, which says its columns are orthonormal. Such a matrix preserves everything geometric: $\|Q\mathbf{x}\| = \|\mathbf{x}\|$ and $(Q\mathbf{x})\cdot(Q\mathbf{y}) = \mathbf{x}\cdot\mathbf{y}$. The orthogonal matrices with determinant $+1$ are exactly the rotations, and those with determinant $-1$ include the reflections.

The check below uses a rotation matrix. It confirms $R^\top R = I$, and that the rotation keeps lengths and dot products.

```python
import numpy as np

theta = 0.7
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])
x = np.array([3.0, -1.0])
y = np.array([0.5, 2.0])

print("R^T R = I:", np.allclose(R.T @ R, np.eye(2)))  # prints: R^T R = I: True
print("length preserved:", np.isclose(np.linalg.norm(R @ x), np.linalg.norm(x)))  # prints: length preserved: True
print("dot product preserved:", np.isclose(np.dot(R @ x, R @ y), np.dot(x, y)))  # prints: dot product preserved: True
```

In words: all three checks pass. The rotation changes where $\mathbf{x}$ and $\mathbf{y}$ point but not how long they are or how far apart their directions are. That is the content of orthogonality: a change of orthonormal basis is a rotation, and it changes no geometry.

<Callout type="pitfall">
Orthogonal does not mean orthonormal, and the matrix $Q$ with orthogonal but non-unit columns is not an orthogonal matrix. Check the lengths as well as the perpendicularity, or the identity $Q^\top Q = I$ will fail.
</Callout>

## Why orthonormal bases are stable

Nearly parallel vectors make a poor basis: a tiny error in the data produces a large error in the coordinates. An orthonormal basis avoids this. Classical Gram-Schmidt as written above slowly loses orthogonality in floating point, so libraries use modified Gram-Schmidt or Householder reflections, which is what `np.linalg.qr` does. Orthonormal bases keep errors from growing, which is why numerical libraries use them for least squares, eigenvalue computation and the decompositions in a later note.
