A polynomial is the simplest function a computer can evaluate: it needs only additions and multiplications. Many useful functions, such as $e^x$, $\sin x$ and $\ln(1+x)$, are not polynomials, but near a point they look like one. The Taylor polynomial is the polynomial that matches a function at a point to as high an order as you choose. This note builds the polynomial from derivatives, shows how the error behaves, and lists the expansions to remember.

## Matching derivatives

Suppose $f$ is smooth near $a$. We want a polynomial $P$ with $P(a) = f(a)$, $P'(a) = f'(a)$, $P''(a) = f''(a)$, and so on up to degree $n$. Writing $P(x) = \sum c_k (x - a)^k$ and differentiating shows that the coefficients must be $c_k = \frac{f^{(k)}(a)}{k!}$. So

$$
P_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k.

$$

The factorial in the denominator undoes the $k$ factors produced by differentiating $(x-a)^k$ $k$ times. For $e^x$ every derivative is $e^x$, so at $a = 0$ every coefficient is $\frac{1}{k!}$, and $P_n(x) = \sum_{k=0}^{n} \frac{x^k}{k!}$.

## Watching the error shrink

The script below evaluates $e^1$ with polynomials of increasing degree, and compares with the exact value.

```python
import math

def taylor_exp(x, n):
    return sum(x ** k / math.factorial(k) for k in range(n + 1))

x = 1.0
for n in [1, 2, 4, 8]:
    print(f"e^x, degree {n}: {taylor_exp(x, n):.8f} error {abs(math.exp(x) - taylor_exp(x, n)):.2e}")
print("exact e =", round(math.e, 8))
# e^x, degree 1: 2.00000000 error 7.18e-01
# e^x, degree 2: 2.50000000 error 2.18e-01
# e^x, degree 4: 2.70833333 error 9.95e-03
# e^x, degree 8: 2.71827877 error 3.06e-06
# exact e = 2.71828183
```

In words: degree $1$ gives $2$, degree $2$ gives $2.5$, and degree $8$ gives $2.71827877$, within $3 \times 10^{-6}$ of $e$. Each term is smaller than the one before, so the series settles quickly for $x = 1$. The error falls off like $\frac{1}{(n+1)!}$, which is why factorial growth in the denominator makes these series so effective.

The same construction works for $\sin x$, whose derivatives cycle through $\sin$, $\cos$, $-\sin$, $-\cos$, so only odd powers appear:

```python
import math

def taylor_sin(x, n):
    return sum((-1) ** k * x ** (2 * k + 1) / math.factorial(2 * k + 1) for k in range(n // 2 + 1))

for n in [1, 3, 5]:
    print(f"sin(1), degree {n}: {taylor_sin(1.0, n):.8f} error {abs(math.sin(1.0) - taylor_sin(1.0, n)):.2e}")
# sin(1), degree 1: 1.00000000 error 1.59e-01
# sin(1), degree 3: 0.83333333 error 8.14e-03
# sin(1), degree 5: 0.84166667 error 1.96e-04
```

In words: the degree-$5$ polynomial already matches $\sin 1$ to about $2 \times 10^{-4}$, using only the terms $x$, $x^3/3!$ and $x^5/5!$.

## Bounding the error

Taylor's theorem says the error of the degree-$n$ polynomial is $\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}$ for some $\xi$ between $a$ and $x$. If the derivative is bounded by $M$ on the interval, the error is at most $\frac{M}{(n+1)!}|x - a|^{n+1}$. For $e^x$ on $[0, 1]$, $M = e$, so the error at degree $n$ is at most $\frac{e}{(n+1)!}$. The check below confirms this bound at degree $6$.

```python
import math

def taylor_exp(x, n):
    return sum(x ** k / math.factorial(k) for k in range(n + 1))

n = 6
print("error at degree 6 is below e/7! :", abs(math.e - taylor_exp(1, n)) <= math.e / math.factorial(n + 1))
# error at degree 6 is below e/7! : True
```

In words: the bound holds, so the degree-$6$ polynomial is guaranteed to be within $e/7! \approx 0.00052$ of $e^x$ for every $x$ in $[0, 1]$. A bound like this is what lets an engineer choose the number of terms in advance.

<Callout type="pitfall">
A Taylor polynomial is accurate near its centre $a$ and can be terrible far away. The degree-$8$ polynomial for $e^x$ is excellent at $x = 1$, but at $x = 10$ it is off by thousands. Check the interval where you need the approximation.
</Callout>

## Big-O notation for error

The error of the degree-$n$ polynomial is often written $O\big((x - a)^{n+1}\big)$: as $x \to a$ it is at most a constant times $(x - a)^{n+1}$. So $e^x = 1 + x + \frac{x^2}{2} + O(x^3)$ says the error of the quadratic shrinks like $x^3$ near $0$: halve $x$ and it falls by about eight. A **little-o** term $o\big((x-a)^n\big)$ means the error shrinks faster than $(x - a)^n$. The same notation counts steps in algorithm analysis, as $n \to \infty$ instead of $x \to a$; see the [Big-O notation](../../../cs/algorithms/big-o-notation/) note.

## Common expansions

These are worth knowing by heart:

- $e^x = \sum_{k=0}^{\infty} \frac{x^k}{k!}$ for all $x$.
- $\sin x = \sum_{k=0}^{\infty} (-1)^k \frac{x^{2k+1}}{(2k+1)!}$ for all $x$.
- $\cos x = \sum_{k=0}^{\infty} (-1)^k \frac{x^{2k}}{(2k)!}$ for all $x$.
- $\ln(1 + x) = \sum_{k=1}^{\infty} (-1)^{k+1} \frac{x^k}{k}$ for $-1 < x \le 1$.
- $\frac{1}{1-x} = \sum_{k=0}^{\infty} x^k$ for $|x| < 1$.

SymPy produces any of these directly, which is a quick way to check a hand expansion:

```python
import sympy as sp

x = sp.symbols("x")
print(sp.series(sp.exp(x), x, 0, 4))
print(sp.series(sp.log(1 + x), x, 0, 4))
# 1 + x + x**2/2 + x**3/6 + O(x**4)
# x - x**2/2 + x**3/3 + O(x**4)
```

In words: the output lists the polynomial and the order of the error that remains, the $O(x^4)$ of the previous section. Run it with `uv run --with sympy`.

## Where Taylor series are used

Math libraries evaluate $\sin$, $\exp$ and $\log$ with polynomials after reducing the argument to a small range. They usually use minimax polynomials, which spread the error evenly over that range, rather than Taylor polynomials, but the Taylor series is where the idea starts. Physics uses the first few terms to linearise nonlinear systems, which is why a pendulum swinging at small angles behaves like a simple harmonic oscillator. Numerical methods and gradient-based optimisation are built on the same idea: approximate locally, then improve.
