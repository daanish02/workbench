A curve tells you where you are; its derivative tells you how fast you are changing. A car's position is a function of time, and its velocity is the derivative of position. A population grows at a rate that is the derivative of its size. The derivative is the tool that turns a function into its rate of change at every point. This note defines the derivative as a limit, computes it numerically, and states the rules that make it practical: power, product and chain.

## The derivative as a limit

Take a point $a$ and a nearby point $a + h$. The slope of the line through $(a, f(a))$ and $(a+h, f(a+h))$ is the difference quotient

$$
\frac{f(a+h) - f(a)}{h}.

$$

As $h$ shrinks, this line turns into the tangent line at $a$. The derivative is the limit of the difference quotient, which is where the [Limits](../limits/) note comes in:

$$
f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}.

$$

The script below takes $f(x) = x^3$ at $a = 2$, where the true derivative is $3 \cdot 2^2 = 12$, and watches the difference quotient approach it.

```python
def f(x):
    return x ** 3

a = 2.0
for h in [0.1, 0.001, 0.00001]:
    print(f"h = {h:>8}: difference quotient = {(f(a + h) - f(a)) / h:.6f}")
print("exact f'(2) = 12")
# h =      0.1: difference quotient = 12.610000
# h =    0.001: difference quotient = 12.006001
# h =    1e-05: difference quotient = 12.000060
# exact f'(2) = 12
```

In words: at $h = 0.1$ the quotient is $12.61$, at $h = 0.00001$ it is $12.00006$. The error shrinks roughly in proportion to $h$, and the limit is $12$.

## The rules

Computing limits of difference quotients by hand is slow, so calculus gives rules. The most used are:

- **Power rule:** $\frac{d}{dx} x^n = n x^{n-1}$ for any real $n$.
- **Constant multiple and sum:** $(cf)' = cf'$ and $(f + g)' = f' + g'$.
- **Product rule:** $(fg)' = f'g + fg'$.
- **Quotient rule:** $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$.
- **Chain rule:** $(f \circ g)'(x) = f'(g(x))\,g'(x)$.

Together with a few basic derivatives, these rules differentiate almost every formula you will meet:

| Function | Derivative | Why |
| --- | --- | --- |
| $e^x$ | $e^x$ | the defining property of $e$ |
| $\ln x$ | $\frac{1}{x}$ | inverse of $e^x$: if $y = \ln x$ then $x = e^y$ and $\frac{dx}{dy} = x$ |
| $\sin x$, $\cos x$ | $\cos x$, $-\sin x$ | from $\frac{\sin h}{h} \to 1$ in the [Limits](../limits/) note (radians only) |
| $\tan x$ | $\sec^2 x = \frac{1}{\cos^2 x}$ | quotient rule on $\frac{\sin x}{\cos x}$ |

The product and chain rules are the ones to check numerically, since they are easy to misapply. The script below checks both at $x = 1.5$ with $f(x) = x^3$, $g(x) = \sin x$, and the composition $\sin(x^2)$. It uses the **central difference** $\frac{f(x + h) - f(x - h)}{2h}$ rather than the one-sided quotient above: the errors on the two sides cancel, so its error shrinks like $h^2$ instead of $h$.

```python
import math

def f(x):
    return x ** 3

def df(x):
    return 3 * x * x

g = lambda x: math.sin(x)
dg = lambda x: math.cos(x)

x0, h = 1.5, 1e-6
lhs = (f(x0 + h) * g(x0 + h) - f(x0 - h) * g(x0 - h)) / (2 * h)
rhs = df(x0) * g(x0) + f(x0) * dg(x0)
print("product rule holds:", math.isclose(lhs, rhs, rel_tol=1e-6))

k = lambda x: math.sin(x * x)
num = (k(x0 + h) - k(x0 - h)) / (2 * h)
print("chain rule holds:", math.isclose(num, 2 * x0 * math.cos(x0 * x0), rel_tol=1e-6))
# product rule holds: True
# chain rule holds: True
```

In words: both checks pass. The chain rule for $\sin(x^2)$ says the derivative is $2x\cos(x^2)$: the outer derivative $\cos$ evaluated at the inner function, times the inner derivative $2x$. Numerical differentiation confirms the formula without trusting the algebra.

A computer algebra system applies the same rules symbolically, which is the quickest way to check a hand derivation:

```python
import sympy as sp

x = sp.symbols("x")
print(sp.diff(x**3 * sp.sin(x), x))
print(sp.diff(sp.sin(x**2), x))
print(sp.diff(sp.tan(x), x).equals(sp.sec(x)**2))
# x**3*cos(x) + 3*x**2*sin(x)
# 2*x*cos(x**2)
# True
```

In words: SymPy returns the product rule's two terms, the chain rule's $2x\cos(x^2)$, and confirms the $\tan$ entry of the table. Run it with `uv run --with sympy`.

<Callout type="pitfall">
Forgetting the inner derivative in the chain rule is the most common error. $\frac{d}{dx} \sin(x^2)$ is $\cos(x^2)$ only if you also multiply by $2x$. Ask of every composed function: what is the inside, and what is its derivative?
</Callout>

## What the derivative tells you

The sign of $f'$ says whether $f$ is increasing or decreasing. Its size says how fast. A derivative of zero marks a flat point, which may be a maximum, a minimum or a level stretch. The next note uses this to find optimal values and to sketch curves.

## Why this matters for learning

A neural network is a long composition of functions, and training it means computing the derivative of a loss with respect to every weight. Backpropagation is the chain rule, applied from the output back to the input, one layer at a time. The rules here are exactly what the training code applies, many times over.
