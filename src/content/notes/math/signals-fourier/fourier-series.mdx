Many signals repeat: a musical note, the voltage in a mains supply, the seasonal pattern in a sales chart. Fourier's idea is that any reasonable repeating signal is a sum of pure sine and cosine waves at integer multiples of a base frequency. Each term is a harmonic, and the list of coefficients is the signal's spectrum. This note states the series, derives the coefficients from orthogonality, and checks the square wave numerically, including the overshoot at its jumps.

## The series

For a function with period $2\pi$,

$$
f(t) = \frac{a_0}{2} + \sum_{k=1}^{\infty} \left(a_k \cos kt + b_k \sin kt\right).
$$

The integer multiples $k$ are the harmonics. The coefficient $a_k$ measures how strongly the $k$-th harmonic cosine is present, and $b_k$ does the same for the sine.

## The coefficient formulas

Over one period, $\sin kt \cos jt$ always integrates to zero, and $\sin kt \sin jt$ and $\cos kt \cos jt$ integrate to zero unless $k = j$. That is orthogonality. Multiplying the series by $\cos kt$ or $\sin kt$ and integrating therefore isolates one coefficient:

$$
a_k = \frac{1}{\pi}\int_{-\pi}^{\pi} f(t)\cos kt\,dt, \qquad b_k = \frac{1}{\pi}\int_{-\pi}^{\pi} f(t)\sin kt\,dt.
$$

The script below computes $b_1$ for the square wave $f(t) = \operatorname{sign}(\sin t)$ by a midpoint sum. The exact value is $\frac{4}{\pi}$.

```python
import math

def f(t):
    return 1.0 if math.sin(t) >= 0 else -1.0

n = 200000
h = 2 * math.pi / n
b1 = sum(f(-math.pi + (i + 0.5) * h) * math.sin(-math.pi + (i + 0.5) * h) for i in range(n)) * h / math.pi
print("numeric b_1:", round(b1, 6), " exact 4/pi:", round(4 / math.pi, 6))  # prints: numeric b_1: 1.27324 exact 4/pi: 1.27324
```

In words: the numerical and exact values agree to six places. The integral picks out the first sine harmonic because every other harmonic averages to zero against it.

## The square wave

The square wave has the series $f(t) = \frac{4}{\pi}\sum_{k\text{ odd}} \frac{\sin kt}{k}$. The script below keeps the odd harmonics up to $k = N$ (so $N = 15$ means eight harmonics) and evaluates the partial sums at $t = \frac{\pi}{2}$, where $f = 1$, and near the jump at $t = 0$.

```python
import math

def partial(t, N):
    return (4 / math.pi) * sum(math.sin(k * t) / k for k in range(1, N + 1, 2))

for N in [1, 3, 7, 15]:
    print(f"N = {N:>2}: partial sum at pi/2 = {partial(math.pi / 2, N):.6f}")
for N in [15, 63, 255]:
    peak = max(partial(i * math.pi / (40 * N), N) for i in range(1, 200))   # search just right of the jump
    print(f"N = {N:>3}: largest value near the jump = {peak:.4f}")
# N =  1: partial sum at pi/2 = 1.273240
# N =  3: partial sum at pi/2 = 0.848826
# N =  7: partial sum at pi/2 = 0.921583
# N = 15: partial sum at pi/2 = 0.960364
# N =  15: largest value near the jump = 1.1801
# N =  63: largest value near the jump = 1.1790
# N = 255: largest value near the jump = 1.1790
```

In words: at $t = \frac{\pi}{2}$ the partial sums $1.273$, $0.849$, $0.922$, $0.960$ close in on $1$ from alternating sides as harmonics are added. Near the jump the story differs: the largest value of each partial sum stays near $1.18$, about $9\%$ of the jump height of $2$ above the target, however many terms are added. That is the Gibbs phenomenon of the pitfall below.

<Callout type="pitfall">
The partial sums of a square wave overshoot the jump by about nine percent of its height, and adding terms moves the overshoot closer to the jump without shrinking it. Gibbs phenomenon is a property of discontinuities, not a sign of a wrong formula.
</Callout>

## Why the coefficients matter

The sizes of $a_k$ and $b_k$ are the spectrum of the signal. Filters, compression and noise removal all act by changing particular coefficients. The series is often written more compactly with complex exponentials, $f(t) = \sum_{k=-\infty}^{\infty} c_k e^{ikt}$ with $c_k = \frac{1}{2\pi}\int_{-\pi}^{\pi} f(t) e^{-ikt}\,dt$, using Euler's formula from the [Complex Numbers](../../foundations/complex-numbers/) note; the pair $c_k$, $c_{-k}$ carries the same information as $a_k$, $b_k$. The next note moves from periodic signals to signals that do not repeat, using the same idea with a continuous set of frequencies.
