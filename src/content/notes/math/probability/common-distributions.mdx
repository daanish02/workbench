Most probability problems reuse a small set of distributions. Each one is the right model for a particular kind of experiment: counting successes in fixed trials, counting arrivals in a time window, measuring a quantity that is the sum of many small effects, or waiting for something to happen. This note defines the five most common distributions, computes probabilities with them, and checks the links between them.

## The binomial distribution

Run $n$ independent trials, each succeeding with probability $p$, and count the successes $X$. The probability of exactly $k$ successes is

$$
P(X = k) = \binom{n}{k} p^k (1 - p)^{n - k}.
$$

The factor $\binom{n}{k}$ counts the orderings of the $k$ successes among $n$ trials. The script below computes $P(X = 3)$ for ten trials with $p = 0.3$.

```python
import math

def binom_pmf(k, n, p):
    return math.comb(n, k) * p ** k * (1 - p) ** (n - k)

print("binomial P(X = 3), n = 10, p = 0.3:", round(binom_pmf(3, 10, 0.3), 4))
print("mean n p =", 10 * 0.3, " variance n p (1 - p) =", round(10 * 0.3 * 0.7, 2))
# binomial P(X = 3), n = 10, p = 0.3: 0.2668
# mean n p = 3.0  variance n p (1 - p) = 2.1
```

In words: with ten trials at $30\%$ each, three successes is the single most likely count near the mean of $3$. The mean is $np$ and the variance is $np(1 - p)$, which you can derive from the sum of $n$ independent trials.

## The Poisson distribution

The Poisson distribution counts events in a fixed window when they happen at a steady average rate $\lambda$: calls to a switchboard in an hour, typos on a page, photons on a sensor. Its probabilities are

$$
P(X = k) = e^{-\lambda}\,\frac{\lambda^k}{k!}, \qquad k = 0, 1, 2, \dots
$$

The mean and variance are both $\lambda$. The script below checks $P(X = 2)$ for $\lambda = 3$ and then shows the binomial approaching the Poisson when there are many trials with small $p$.

```python
import math

def binom_pmf(k, n, p):
    return math.comb(n, k) * p ** k * (1 - p) ** (n - k)

lam = 3
print("Poisson P(X = 2), lambda = 3:", round(math.exp(-lam) * lam ** 2 / math.factorial(2), 4))
n = 1000
print("binomial n = 1000, p = 0.003, P(X = 2):", round(binom_pmf(2, n, lam / n), 4))
# Poisson P(X = 2), lambda = 3: 0.224
# binomial n = 1000, p = 0.003, P(X = 2): 0.2242
```

In words: a thousand trials with a tiny chance each give almost the same answer as the Poisson formula. That is why the Poisson describes rare events in a large number of opportunities.

## The normal distribution

The normal distribution with mean $\mu$ and variance $\sigma^2$ has the density

$$
f(x) = \frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{(x - \mu)^2}{2\sigma^2}}.
$$

Its CDF has no elementary formula, so it is written $\Phi$ for the standard case $\mu = 0$, $\sigma = 1$. The function $\Phi$ is available through the error function in Python's `math` module, and directly as `statistics.NormalDist().cdf` in the standard library.

```python
import math

def Phi(x):
    return 0.5 * (1 + math.erf(x / math.sqrt(2)))

print("normal P(-1 < Z < 1):", round(Phi(1) - Phi(-1), 6))
print("normal P(-2 < Z < 2):", round(Phi(2) - Phi(-2), 6))
# normal P(-1 < Z < 1): 0.682689
# normal P(-2 < Z < 2): 0.9545
```

In words: about $68\%$ of the mass lies within one standard deviation of the mean, and about $95\%$ within two. These are the numbers behind most confidence intervals later in the course.

## The exponential distribution

The exponential distribution with rate $\lambda$ has density $f(x) = \lambda e^{-\lambda x}$ for $x \ge 0$. Its tail is $P(X > t) = e^{-\lambda t}$. It is the waiting time between events in a Poisson process, and it is the only continuous distribution with no memory.

```python
import math

rate = 2
print("exponential P(X > 1), rate 2:", round(math.exp(-rate * 1), 6))
s, t = 0.5, 1.0
print("memoryless: P(X > s + t | X > s) =", round(math.exp(-rate * (s + t)) / math.exp(-rate * s), 6), " P(X > t) =", round(math.exp(-rate * t), 6))
# exponential P(X > 1), rate 2: 0.135335
# memoryless: P(X > s + t | X > s) = 0.135335  P(X > t) = 0.135335
```

In words: knowing you have already waited half a unit changes nothing about the remaining wait. The two printed values match, which is the memoryless property written as a check.

## The uniform distribution

The uniform distribution on $[a, b]$ has constant density $\frac{1}{b - a}$. A probability is just a length divided by the total length.

```python
a, b = 2, 5
print("uniform(2, 5) P(3 <= X <= 4):", (4 - 3) / (b - a))
# uniform(2, 5) P(3 <= X <= 4): 0.3333333333333333
```

In words: the interval $[3, 4]$ has length $1$ out of a total length $3$, so it has probability one third.

<Callout type="pitfall">
Do not model everything as normal. Counts are not normal when they are small or bounded, and waiting times are not normal because they cannot be negative. Choose the distribution from how the data are generated, then check its shape against the data.
</Callout>

## More families

A few more distributions appear constantly in later notes:

| Distribution | Models | Mean | Variance |
| --- | --- | --- | --- |
| Geometric$(p)$ | trials up to and including the first success | $\frac{1}{p}$ | $\frac{1 - p}{p^2}$ |
| Beta$(\alpha, \beta)$ | a probability that is itself uncertain, on $[0, 1]$ | $\frac{\alpha}{\alpha + \beta}$ | $\frac{\alpha\beta}{(\alpha + \beta)^2(\alpha + \beta + 1)}$ |
| Gamma$(k, \theta)$ | waiting time for the $k$-th event of a Poisson process | $k\theta$ | $k\theta^2$ |
| Student $t_\nu$ | a standardised mean when $\sigma$ is estimated | $0$ (for $\nu > 1$) | $\frac{\nu}{\nu - 2}$ (for $\nu > 2$) |
| Chi-square $\chi^2_k$ | a sum of $k$ squared standard normals | $k$ | $2k$ |

Every family in this table is also in the explorer above, along with the five from the earlier sections. Turn on the normal overlay to see how each one differs from the bell curve: the geometric and chi-square are skewed, the beta is bounded, and the $t$ with few degrees of freedom has heavier tails, the theme of the [Heavy Tails](../heavy-tails/) note.

The geometric is the discrete cousin of the exponential and is also memoryless. The Beta is the prior of the [Bayesian Inference](../../statistics/bayesian-inference/) note, the $t$ drives the small-sample intervals of [Confidence Intervals](../../statistics/confidence-intervals/), and the [Multivariate Normal](../multivariate-normal/) note extends the normal to vectors.

Every family here is in `scipy.stats` with the same interface, `pmf` or `pdf`, `cdf`, `mean`, `var` and `rvs` for sampling, which makes a good check on the hand formulas above:

```python
from scipy import stats

print("binomial P(X = 3), n = 10, p = 0.3:", round(stats.binom.pmf(3, 10, 0.3), 4))
print("Poisson P(X = 2), lambda = 3:", round(stats.poisson.pmf(2, 3), 4))
print("normal P(-1 < Z < 1):", round(stats.norm.cdf(1) - stats.norm.cdf(-1), 6))
print("geometric mean and variance, p = 0.25:", stats.geom.mean(0.25), stats.geom.var(0.25))
print("Beta(8, 4) mean:", round(stats.beta.mean(8, 4), 4), " t(24) variance:", round(stats.t.var(24), 4))
# binomial P(X = 3), n = 10, p = 0.3: 0.2668
# Poisson P(X = 2), lambda = 3: 0.224
# normal P(-1 < Z < 1): 0.682689
# geometric mean and variance, p = 0.25: 4.0 12.0
# Beta(8, 4) mean: 0.6667  t(24) variance: 1.0909
```

In words: SciPy reproduces the binomial, Poisson and normal values computed by hand earlier, and the table's mean $4$ and variance $12$ for a geometric with $p = \frac{1}{4}$. Run it with `uv run --with scipy`.

## Choosing a distribution

Ask how the randomness arises. Yes-or-no trials with a fixed count give the binomial. Events at a steady rate in a window give the Poisson. Waiting times with no memory give the exponential. Sums of many small independent effects give the normal, a claim the [central limit theorem](../central-limit-theorem/) makes precise later in this section.
