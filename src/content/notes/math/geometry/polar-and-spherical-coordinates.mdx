A map gives positions as latitude and longitude, a radar gives bearing and range, and a robot arm describes its joints by angles. Each uses a coordinate system chosen for the problem. Cartesian coordinates $(x, y)$ measure along two fixed directions, which is simple for grids, but awkward when the picture is round. Polar and spherical coordinates measure from a centre instead, which makes circles and spheres simple. This note converts between the systems and shows when each one is the natural choice.

## Polar coordinates

A point in the plane is described by $r \ge 0$, its distance from the origin, and $\theta$, the angle from the positive $x$-axis, measured anticlockwise. The two systems are related by

$$x = r\cos\theta, \qquad y = r\sin\theta,$$

and in the other direction by $r = \sqrt{x^2 + y^2}$ and $\tan\theta = y/x$. The last formula loses information, because $\tan$ repeats every $\pi$, so $\theta$ must be chosen to match the quadrant of $(x, y)$. The function `atan2(y, x)` does this automatically and is what programs should use.

The script below converts a few points both ways and checks a round trip over a grid of 120 points.

```python
import math

def to_polar(x, y):
    return math.hypot(x, y), math.atan2(y, x)

def to_cartesian(r, theta):
    return r * math.cos(theta), r * math.sin(theta)

print("(3, 4) in polar:", tuple(round(v, 4) for v in to_polar(3, 4)))
r, th = to_polar(-1, 1)
print("(-1, 1) in polar: r =", round(r, 4), "theta =", round(th / math.pi, 4), "pi")
x, y = to_cartesian(2, math.pi / 3)
print("(r=2, theta=pi/3) back to Cartesian:", round(x, 4), round(y, 4))

worst = 0.0
for x in range(-5, 6):
    for y in range(-5, 6):
        if x == 0 and y == 0:
            continue
        r, th = to_polar(x, y)
        x2, y2 = to_cartesian(r, th)
        worst = max(worst, math.dist((x, y), (x2, y2)))
print("worst round-trip error:", f"{worst:.1e}")
```

In words: $(3, 4)$ has distance $5$ from the origin. The point $(-1, 1)$ sits in the second quadrant, so its angle is $\frac{3}{4}\pi$ and not the $-\frac{\pi}{4}$ that a plain arctangent would give. Converting $(2, \pi/3)$ back gives $(1, \sqrt{3})$, and the round trip over the grid is accurate to about $10^{-15}$.

## Why polar is natural

Some curves are simple in polar form and messy in Cartesian. A circle of radius $a$ centred at the origin is $r = a$. A spiral is $r = a\theta$. A rose with petals is $r = \cos(k\theta)$. In Cartesian form, the circle is $x^2 + y^2 = a^2$, which is still simple, but the spiral and rose need implicit equations that are much harder to work with.

Rotation is also simpler. Rotating a point by $\alpha$ in polar form changes only the angle: $(r, \theta) \mapsto (r, \theta + \alpha)$. In Cartesian form the same rotation needs a matrix, as shown in [Geometric Transformations](../geometric-transformations/).

## Spherical coordinates

In three dimensions, a point is described by three numbers. The standard convention uses $\rho \ge 0$ for the distance from the origin, $\theta$ for the angle around the $z$-axis (the same as polar $\theta$), and $\varphi$ for the angle down from the positive $z$-axis, from $0$ to $\pi$. Then

$$x = \rho\sin\varphi\cos\theta, \qquad y = \rho\sin\varphi\sin\theta, \qquad z = \rho\cos\varphi.$$

The script below converts the point $(1, 1, \sqrt{2})$ to spherical coordinates and back. It is on the sphere of radius $2$, because $1 + 1 + 2 = 4$.

```python
import math

def to_spherical(x, y, z):
    rho = math.sqrt(x * x + y * y + z * z)
    theta = math.atan2(y, x)
    phi = math.acos(z / rho)
    return rho, theta, phi

def from_spherical(rho, theta, phi):
    return (rho * math.sin(phi) * math.cos(theta),
            rho * math.sin(phi) * math.sin(theta),
            rho * math.cos(phi))

rho, th, ph = to_spherical(1, 1, math.sqrt(2))
print("spherical of (1, 1, sqrt 2): rho =", round(rho, 4), "theta =", round(th / math.pi, 4),
      "pi, phi =", round(ph / math.pi, 4), "pi")
print("spherical round trip:", tuple(round(v, 4) for v in from_spherical(rho, th, ph)))
```

In words: $\rho = 2$, $\theta = \frac{\pi}{4}$ and $\varphi = \frac{\pi}{4}$, which is a point halfway from the north pole to the equator, a quarter turn around. The round trip returns the original $(1, 1, \sqrt{2})$.

<Callout type="pitfall">
Conventions differ. Physics often swaps $\theta$ and $\varphi$, using $\theta$ for the angle from the $z$-axis, so a formula copied from a physics text may be wrong in a maths text. Check which angle is which before using a formula.
</Callout>

## Where each is used

Use Cartesian coordinates for grids and rectangular boundaries. Use polar for anything rotational: wheels, orbits, radar sweeps. Use spherical for anything with a centre and a sphere of symmetry: the gravitational field of a planet, the sky as seen from a point, the direction a light ray travels from a point source. Choosing the system that matches the symmetry often turns an integral from hard to routine.
